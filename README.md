# Energy & Sustainability Dashboard (BI Portfolio)

An interactive, Power BI-like dashboard that tells a simple story about **decarbonization**, **renewables adoption**, and the **income-vs-emissions** relationship.

## Live dashboard (GitHub Pages)

After you enable GitHub Pages, your public URL will look like:

![Repository](https://<YOUR_GITHUB_USERNAME>.github.io/<REPO_NAME>/)

## What you can do in the dashboard

- Use the **Country** dropdown to filter a single country or compare **All Countries**.
- Explore three coordinated views:
  1) CO2 per capita (time-series)
  2) Renewables share (time-series)
  3) GDP vs CO2 per capita (2024 cross-section)
